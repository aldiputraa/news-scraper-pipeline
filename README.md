# Simple News Scraper Pipeline
Proyek ini adalah demonstrasi pipeline data sederhana menggunakan **Python** untuk mengambil data dari portal berita (Web Scraping) dan menyimpannya ke dalam database relasional **SQLite**.

### Tech Stack:
- **Language:** Python 3
- **Libraries:** Beautifulsoup4, Requests
- **Database:** SQLite3
- **Containerization:** Docker

### Cara Menjalankan:
1. Install dependencies: `pip install -r requirements.txt`
2. Jalankan skrip: `python3 scraper.py`
